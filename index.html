# Clear Human Writing / 自然、准确、直接

项目里的主要内容

  • 通用与技术写作

    删除公式化开头、空泛拔高和重复表达。

  • 学术与基金文本

    在学术和基金文本中保留术语、数据、引用及证据限定。

  • 去模板化及多余防御措辞

    减少无必要的防御措辞，同时保留会影响判断的条件。

使用入口

npx skills add tangyixiao/clear-human-writing --global --agent codex
